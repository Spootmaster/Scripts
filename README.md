# Scripts
Useful Scripts I've created in the past I wanted to save. :)

All Scripts in PDQ Scripts have been tested and used in my production. Most are created to be slient and to not elevate automatically because pdq runs most scripts on the local service account. 
I'll make a note in the script if it needs to be run as logged on user. 
A good example of this are computer restart notifications as if they are not run as logged on user they will make the notification happen on the local account which the user can not see.
